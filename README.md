# consulta-loterica
Realiza uma consulta na API oficial da loterica e realiza alguns métodos.
sendo eles:
1. Retorna os três numeros mais sorteados da megasena;
2. Retorna os três numeros menos sorteados da megasena;
3. Retorna o concurso com menos ganhadores na quina;
4. Retorna a quantia de concursos em que não houveram ganhadores na sena.
